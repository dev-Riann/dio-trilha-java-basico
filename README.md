# ☕ Trilha Java Básico - DIO

Este repositório contém os desafios e exercícios práticos desenvolvidos durante a **Trilha Java Básico** da [Digital Innovation One (DIO)](https://www.dio.me/). O objetivo é consolidar os fundamentos da linguagem Java, explorando desde a sintaxe básica até a interação com o usuário via terminal.

## 🚀 O que eu pratiquei:

* **Sintaxe Java:** Declaração de variáveis, tipos primitivos e convenções de nomenclatura.
* **Operadores:** Aritméticos, relacionais e lógicos.
* **Terminal e Argumentos:** Execução de programas via linha de comando e passagem de parâmetros no `main(String[] args)`.
* **Interatividade com Scanner:** Captura de dados do teclado em tempo real com tratamento de tipos (int, double, String).
* **Estruturas de Dados:** Uso de Arrays para manipulação de listas de argumentos.
* **Configuração de Ambiente:** Organização de diretórios (`src` vs `bin`) e ajustes de compilação no VS Code.

## 📁 Estrutura do Projeto

* `java-terminal/`: Exercícios focados em execução via terminal e uso da classe `Scanner`.
* `sistema-smart-tv/`: Desafio prático simulando as funções de uma Smart TV para exercitar métodos e lógica.
